# 群雄逐鹿（中等版）

三國題材的原創回合制策略遊戲。單一 HTML 檔，用瀏覽器開啟即可遊玩，手機與電腦都能玩，不需要安裝或伺服器。

**線上遊玩：** `https://<你的帳號>.github.io/<倉庫名>/`（部署後把這行換成實際網址）

## 特色

- **30 座城池、約 100 名武將**，地圖依實際地理排列。
- **兩個劇本**
  - 194 年「群雄割據」：12 個勢力
  - 207 年「赤壁前夕」：7 個勢力
- **內政**：開墾、商業、築城、安民、徵兵、訓練、輸送。
- **人事**：登用在野武將（領地內任一城）、處理俘虜、褒賞、在自己的城之間調動武將。
- **計策與外交**：離間、煽動、結盟、贈禮。
- **友好度**：國與國有友好度（開局依歷史關係為 20~80），影響結盟成功率。
- **仇恨值**：武將對各勢力有仇恨值，影響登用成功率。反覆遊說、贈禮可降低；對同一人失敗越多次，下次越容易成功。
- **格子戰場**
  - 每名武將各領一隊兵，兵力、糧食可自行分配。
  - 兵力較多的一方有優勢（每多一倍攻擊力 ×1.2）。
  - 兩隊以上包圍同一敵軍可協同攻擊（2 隊 ×2、3 隊 ×4、4 隊 ×6）。
  - 林地防守較有利；守軍「本陣」依城防獲得最高 5 倍的防守加成。火計攻擊本陣會削減城防而非殺傷士兵。
  - 可親自指揮、自動指揮或自動戰鬥。
- **守城**：被攻擊時可手動防守、自動防守，或撤退到鄰近的城（帶走武將、兵力與金糧）。
- **音樂與音效**：全部由程式即時合成（中國風五聲音階），不需要音檔。

## 玩法

1. 選擇劇本與勢力。
2. 點選地圖上的城池，對自己的城下達指令；每月每位武將可行動一次。
3. 按「結束本月」，電腦勢力行動、月份推進。
4. 目標：25 年內佔領全部 30 座城。

遊戲內的「選單 → 玩法說明」有更詳細的規則。

## 在本機執行

下載 `index.html`，直接用瀏覽器開啟即可。

## 部署到 GitHub Pages

1. 把本資料夾的檔案放到 GitHub 倉庫根目錄。
2. 到 **Settings → Pages**，Source 選 `main` 分支、資料夾選 `/ (root)`，儲存。
3. 等一兩分鐘，網址為 `https://<你的帳號>.github.io/<倉庫名>/`。

## 注意事項

- 存檔放在玩家自己瀏覽器的 localStorage，每位玩家各自一份；換瀏覽器或清除網站資料會遺失進度。
- 字型使用 Google Fonts（Noto Sans TC / Noto Serif TC），離線時會改用系統字型。
- 這是以三國歷史為題材的原創作品，程式、介面與數值皆為原創，與光榮特庫摩（KOEI TECMO）無關，也未使用其任何素材。
